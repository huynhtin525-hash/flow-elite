# FLOW ELITE

App cộng tác viên: nạp, rút, buff, vòng quay, giới thiệu, quản lý admin.

Nguồn đầy đủ nằm trong file nén `FLOW-ELITE-source.zip` (không kèm token Telegram hay sổ dư CTV đang chạy).

## Chạy

```
npm install
npm run dev
```

Gỡ / nối nhóm Telegram không xóa tài khoản, đơn, số dư hay lịch sử.
